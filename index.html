DevOps Lab · Website Delivery

From commit to Kubernetes.

Push a change to GitHub. Jenkins detects it, builds and publishes a Docker image, and rolls the new version out to Kubernetes.

See how it ships ↓

How it ships

  1. 01 · Source

    GitHub

    A commit to main starts the delivery process.

  2. 02 · Build

    Jenkins

    SCM polling detects the commit and triggers a build.

  3. 03 · Publish

    Docker Hub

    The pipeline pushes an image tagged with the commit and build number.

  4. 04 · Deploy

    Kubernetes

    The Deployment targets five replicas. The Service exposes the site on NodePort 30010.

Infrastructure provisioned with Terraform and configured with Ansible.
